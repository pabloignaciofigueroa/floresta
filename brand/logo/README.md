# Logos — Floresta (Fase 05)

Vectorizados con potrace desde los PNG originales (`imagotipo.png`, `isotipo.png`, `logotipo.png`, que siguen intactos en la raíz). Scripts: `tools/vectorize.py` y `tools/brand_assets.py`.

| Archivo | Qué es |
|---|---|
| `logotipo.svg` / `logotipo-claro.svg` | FLORESTA, trazos reales del logo (no una fuente parecida). Color por `currentColor` |
| `firma.svg` / `firma-claro.svg` | Logotipo + "BY ALMÁCIGOS CHILOÉ" (Catamaran 600 a trazos con fontTools, como en la pieza del Día de la Novia) |
| `isotipo.svg` | El ramo: tres capas (hojas menta translúcidas, pétalos coral, línea verde). Clases `iso-coral` e `iso-linea` para animar |
| `isotipo-claro.svg` | Línea crema para fondos oscuros |
| `isotipo-mono.svg` | Solo la línea, en `currentColor` |
| `vertical.svg` / `.png` | Isotipo sobre la firma (equivale al imagotipo original) |
| `favicon.svg` | Isotipo sobre círculo salvia (la mancha salvia de las piezas verdes) |
| `../../assets/icons/` | favicon.ico (16/32/48), icon-16…512.png, apple-touch-icon.png |
| `../../assets/og.jpg` | Imagen para compartir, 1200×630 |

Sobre el campo verde bosque el isotipo va **siempre sobre una mancha salvia**, como en "Debes saber…" y "También puedes venir directamente": la línea oscura no se lee directo sobre el verde.
